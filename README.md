# 💻 Exercícios de Programação & Estrutura de Dados

Repositório pessoal destinado ao armazenamento e organização de resoluções de exercícios de programação, focando na prática de lógica, manipulação de estruturas e conceitos fundamentais das linguagens **C** e **Python**.

---

## 🚀 Linguagens Utilizadas

- **C:** Resoluções focadas em conceitos de baixo/médio nível, como ponteiros, alocação dinâmica de memória, vetores, matrizes e Estrutura de Dados.
- **Python:** Práticas de manipulação de strings, tuplas, estruturas condicionais e rotinas de lógica de programação.
